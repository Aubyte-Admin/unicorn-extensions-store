Quick 30-Second Installation Guide

Firefox Installation:

  1. Download the Firefox Add-on ZIP above.
  2. Open Firefox and go to about:debugging#/runtime/this-firefox
  3. Click "Load Temporary Add-on" and select manifest.json from the zip.

Chrome / Brave / Edge Installation:

  1. Download the Chrome Bundle ZIP and extract it.
  2. Go to chrome://extensions (or edge://extensions).
  3. Enable Developer mode (top-right toggle).
  4. Click "Load unpacked" and choose the extracted folder.
